Контрольные вопросы 

1. Чем fn отличается от function?
    fn — одно выражение, автоматический возврат, автозахват переменных по значению. function — любое тело, нужен return, переменные через use.

2. Как fn захватывает переменные и почему изменение не влияет?
    Автоматически, по значению, в момент создания. Внутри остаётся копия, поэтому изменение внешней переменной не влияет.

3. Можно ли в fn несколько инструкций?
    Нет, только одно выражение. Для сложной логики используют классическую function или тернарный оператор/запятую в массиве.

4. Что возвращают array_map, array_filter, array_reduce?
    array_map — новый массив с применённой функцией к каждому элементу.
    array_filter — массив с элементами, для которых callback вернул true.
    array_reduce — одно значение, свёрнутое из массива.

5. Как работает оператор <=>?
    Возвращает -1, 0 или 1 при сравнении двух значений. Идеально для usort(), который ждёт именно такие значения.

6. Что выведет $f = fn($x) => fn($y) => $x * $y; echo $f(2)(5);?
    Выведет 10. $f(2) возвращает вложенную fn с захваченным $x=2, затем вызов (5) умножает 2*5.
